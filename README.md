# PocketCode Support

PocketCode에 대한 문의, 버그 리포트, 기능 제안을 받는 곳입니다.

## PocketCode란?

데스크톱에서 실행 중인 VS Code 개발 환경에 모바일에서 바로 접속할 수 있는 네이티브 클라이언트입니다.

- VS Code Tunnel / serve-web 연결 지원
- 생체 인증 앱 잠금 (Face ID / Touch ID)
- Siri 단축어로 빠른 접속
- Claude, Codex, Gemini 같은 AI 에이전트도 그대로 사용 가능

## 문의 방법

[Issues](https://github.com/pocketcode-app/support/issues) 탭에서 새 이슈를 생성해 주세요.

- 사용 중인 기기 및 OS 버전
- 재현 절차
- 기대한 동작과 실제 동작
